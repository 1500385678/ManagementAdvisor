## 一、10 大主题速览(每段 100-300 字)

### 1. 管理起源与演变(`01_管理起源与演变/`)

梳理管理从"古代人工分配 → 工业革命 → 泰勒科学管理 → 精细化 → 数字化"的演变时间线。核心回答"管理是什么、从哪来、走到哪去",为后续所有主题定锚坐标。**应用**:管理爱好者的入门第一站、产业链/项目管理者的历史脉络参考。

### 2. 管理分支与特点(`02_管理分支与特点/`)

把管理拆成"产业链 / 生产线 / 人员 / 项目"4 大分支,各分支下罗列研究内容与代表学派。回答"管理这棵大树长了哪些枝"。**应用**:跨学科管理者快速定位自己关心的是哪一支(运营/HR/PM),为知识图谱的"分支节点"提供原语。

### 3. 管理逻辑与推理(`03_管理逻辑与推理/`)

研究"如何从管理现象抽象出普遍规律"——归纳 / 演绎 / 类比 / 模型 4 类推理方法。回答"管理作为一门学科,它的逻辑骨架是什么"。**应用**:AI 诊断 / 教练的推理基础,所有"判断一个管理动作是否合理"都从这里出发。

### 4. 管理故事与传说(`04_管理故事与传说/`)

以叙事形态记录泰勒科学管理、精细化管理、数字化管理等流派的"传奇故事"与"有趣事实"。**应用**:案例库的叙事骨架、AI 讲解时"案例"段的素材池;管理者培训时的开场故事源。

### 5. 管理趣味与游戏(`05_管理趣味与游戏/`)

把"产业链 / 生产线 / 人员"等管理知识做成模拟游戏与趣味实验,降低学习门槛。**应用**:管理沙盘、新晋管理者 onboarding 的"玩中学"工具包,也是 Web App 中"管理趣味实验"模块的内容源。

### 6. 管理大师与学者(`06_管理大师与学者/`)

泰勒、精细化管理、数字化管理等代表人物/学派的"贡献清单 + 经典语录"。**应用**:知识图谱中"学派节点"的内容来源;AI 三件套讲解"理论"段的引语出处。

### 7. 管理思想与方法(`07_管理思想与方法/`)

抽象出"管理思想 = 一组方法 + 一组原则"的结构,如科学管理四原则、精细化五步法等。**应用**:知识图谱中"思想节点"的核心;AI 诊断时调用"应该用什么方法"的检索池。

### 8. 管理应用与建模(`08_管理应用与建模/`)

把前 7 个主题的方法"实例化"——产业链模型、生产线模型、人员配置模型等可计算/可视化的管理模型。**应用**:Web App 中"工具集"模块的可视化底图;AI OKR / 反馈助手的"模型输入"。

### 9. 管理之美(`09_管理之美/`)

跳出"效率/产出"视角,谈管理的审美维度——简洁、节奏、秩序、善意。回答"管理能不能是美的"。**应用**:高管教练、文化建设的素材;Phase 2 "AI 领导力教练"中的"管理哲学"子模块引用源。

### 10. 管理趣闻与奇观(`10_管理趣闻与奇观/`)

边角料但有启发的"趣闻 + 奇观"——泰勒的轶事、数字化管理的有趣故事等。**应用**:内容运营"冷知识"专栏、飞书 Agent 每日推送的轻量素材,起到"软性拉活"作用。
