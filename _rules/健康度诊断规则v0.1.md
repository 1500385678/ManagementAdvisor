# 健康度诊断规则 v0.1

> Phase 0 第 5 项资产 · 2026-08-27 · T2 任务
> 范围:3 类信号 + 风险分级 + 处置动作(简版,可入库)
> 后续:Phase 1 用 v0.1 跑 3 团队 dogfood,反馈后迭代 v0.2

---

## 一、设计原则

1. **只采聚合数据**:团队级指标(均值/分位/趋势),不分析个人;飞书只开放汇总接口
2. **阈值先行,模型后置**:v0.1 全部是规则(无 ML),跑稳后再引入预测模型
3. **风险可视化,不告警轰炸**:一周最多 1 条风险推送,避免"狼来了"
4. **管理者驱动**:不向员工推送诊断结果,只给管理者

---

## 二、3 类信号规则

### 信号 1:响应时长(协作活性)

| 指标 | 公式 | 阈值(周维度) | 风险等级 |
|---|---|---|---|
| 中位响应时长 | P50(消息发出→首次回复) | ≤ 30 min | 绿 |
| 长尾响应 | P90 响应时长 | 30-120 min | 黄 |
| 长尾响应 | P90 响应时长 | > 120 min | 红 |
| 静默率 | 24h 无任何消息成员占比 | ≤ 15% | 绿 |
| 静默率 | 同上 | 15-30% | 黄 |
| 静默率 | 同上 | > 30% | 红 |

**例外**:周末/法定假 日志静默不计入;出差标记的成员静默不计入。

### 信号 2:任务完成率(执行力)

| 指标 | 公式 | 阈值(周维度) | 风险等级 |
|---|---|---|---|
| 周完成率 | 截止本周的任务中已完结比例 | ≥ 80% | 绿 |
| 周完成率 | 同上 | 60-80% | 黄 |
| 周完成率 | 同上 | < 60% | 红 |
| 延期率 | 截止本周的任务中超期未完比例 | ≤ 10% | 绿 |
| 延期率 | 同上 | 10-25% | 黄 |
| 延期率 | 同上 | > 25% | 红 |
| 拖尾任务 | 同一任务超期 2 周以上 | 0 个 | 绿 |
| 拖尾任务 | 同上 | 1-2 个 | 黄 |
| 拖尾任务 | 同上 | ≥ 3 个 | 红 |

### 信号 3:请假模式(过载/异常)

| 指标 | 公式 | 阈值(4 周滑动) | 风险等级 |
|---|---|---|---|
| 请假密度 | 团队人均请假天数 / 4 周 | ≤ 1.5 天 | 绿 |
| 请假密度 | 同上 | 1.5-3 天 | 黄 |
| 请假密度 | 同上 | > 3 天 | 红 |
| 集中请假 | 单周 ≥ 2 人同时请假 | 0 次 | 绿 |
| 集中请假 | 同上 | 1 次/4 周 | 黄 |
| 集中请假 | 同上 | ≥ 2 次/4 周 | 红 |
| 周末消息 | 周末(周六/日)发消息成员数 | ≤ 10% | 绿 |
| 周末消息 | 同上 | 10-25% | 黄 |
| 周末消息 | 同上 | > 25% | 红(过载信号) |

## 三、风险分级

| 等级 | 触发条件 | 处置动作 |
|---|---|---|
| **绿** | 3 类信号全绿 | 周报展示指标,无推送 |
| **黄** | 任 1 类信号黄 | 周报标注"+1 黄灯",管理者查看根因 |
| **橙** | 任 2 类信号黄,或任 1 类红 | 飞书群推送 1 条建议(5 分钟诊断脚本) |
| **红** | 任 2 类信号红,或全部 3 类都黄 | 飞书群推送 + 创建 1v1 复盘任务(14 天) |

**去重**:同一团队同一等级,7 天内不重复推送(避免"狼来了")。
